## 零、先纠正一个误判（必须先说）

**本次自动检测一度报告「五条国内 AI 链路全部阻断、robots.txt 全挡」。该结论是错的，已作废。**

【规则检测·人工复核】
- `https://www.geova.cn/robots.txt` 返回 200，逐段核对：Googlebot / Bingbot / GPTBot / OAI-SearchBot / ChatGPT-User / PerplexityBot / Bytespider / Baiduspider / Sogou / YisouSpider / 360Spider / ToutiaoSpider **全部是 `Allow: /`**。
- 误判原因：解析器把结尾 `User-agent: PetalBot / Disallow: /` 串进了前面所有分组。
- 附带发现（真实且重要）：**Cloudflare 对非浏览器 UA（如 `Python-urllib`）返回 403，对 Googlebot / GPTBot UA 返回 200**。

**这条附带发现需要你亲自确认**：如果 WAF 规则是"非白名单 UA 一律 403"，那些 UA 未被显式放行的 AI 爬虫（新兴的、小众的、各家新出的检索 bot）会被静默拦在门外。既然做 GEO，这是最不该有的暗坑。建议在 Cloudflare 加一条规则：**对声明的 AI 检索爬虫 UA 直接放行，别依赖 robots.txt 单点控制**。

## 一、把"没流量"拆开：三个不同的病，不能一起吃一副药

你说"没流量、没询盘"，但实际是三个独立问题叠加，对应完全不同的解法：

| 层 | 现状判断 | 依据 |
| --- | --- | --- |
| **能不能被找到**（技术） | ⚠️ 有**真实缺陷**（已用 GSC 数据修正） | 收录 59 页正常；但 **22 组 URL 被拆成 44+ 个变体**（尾斜杠/`www`/`http` 三重未统一），权重被稀释 |
| **有没有人搜**（需求） | 🔴 **这是第一问题** | 92 天仅 **113 点击 / 788 展示**，日均 1.23 次点击；`geo优化` 全词只 7 次展示 |
| **来了愿不愿意问**（转化） | 🔴 **也很严重** | 不缺点击入口（首页 CTR 44.78%），但**博客 5 篇 325 展示只换 4 点击（1.23%）**，移动端 CTR 仅 2.08% |

**结论先行（已按 GSC 真实数据重写）：不是"没流量"，是"流量进来了但接不住"。**
92 天 788 次展示、113 次点击，点击量不到日均 1.3 次——这是"品类需求尚未起量"的直接体现；而同期移动端 CTR 2.08%、博客 CTR 1.23%、`/blog/seo-to-geo-2026/` 排名 7.88 位却 0 点击——这是"有曝光但没人点"的呈现问题。**两个问题叠加，才导致询盘为 0。**

## 二、【已作废】原判断："品牌词搜不到"

> **作废说明（2026-11-12 21:36，依据 GSC 真实导出）**：原判断为「品牌词无自然结果召回，说明索引量极低或权重过低」。**GSC 数据证明这是错的。**
> 真实情况：`www.geova.cn` 该查询词 **92 天获得 121 次展示，占全部查询词展示的 68.8%**，平均排名 **18.71**。品牌词不仅有召回，而且是站点最大的曝光来源。
> 原判断错误原因：依赖单次 WebSearch 结果推断索引状态，而第三方搜索页面对小众品牌的召回与 Google 实际索引并不等价。**教训：索引类结论必须以 GSC 为准，不能用第三方搜索替代。**

**修正后的真实问题（同一数据换个角度看）**：品牌词 121 次展示 → **0 次点击**，排名 18.71（第 2 页底部）。首页本身 CTR 高达 44.78%、排名 5.25，说明**用户搜到品牌后确实会点**；那 121 次展示的 0 点击，更可能是排名位置（第 2 页）导致——**品牌词的排名需要从 18.71 提到前 5**。

同时，外部核实到该品类的竞争格局已经变了（【外部核实·未经审计，仅作参考】）：
- 2026 年中文 GEO 市场已出现"榜单/评测/排行榜"型内容霸屏（中国商报网、中国经济新闻网等），这类是**付费软文**性质，占位能力强，你靠自然内容短期抢不动。
- 已有明确打法面向**制造业/工业 B2B**（有服务商宣称占 B2B 工业赛道三成份额）；也有玩家把报价公开化（如"1 万–6 万/年"）。
- 你最大的差异化优势本应是**"geova.cn 自己做 GEO 并公开过程"**——但现在这个优势在站内**完全没有被当成销售证据用**。

## 三、按「问题 → 影响 → 优先级 → 解决」排序

### 🔴 P0-1 收录正常，但 22 组 URL 被拆成 44+ 个变体（GSC 实测证实）

> **修订史（务必看，避免误用旧结论）**
> - 一稿：判「品牌词搜不到 = 可能未被索引」→ **已被 GSC 截图推翻**
> - 二稿：判「索引膨胀，118 vs sitemap 62，存在大量薄页」→ **经实测推翻，作废**
> - 三稿：判「收录正常、canonical 正确」→ **被 GSC 真实导出推翻**：canonical 并没有统一，同页存在多个自指 canonical
> - 四稿（当前，最终）：收录量正常，但 **URL 规范化失效**，这是真实且可修复的技术缺陷

**GSC 实测证据（2026-08-11 ~ 11-10，92 天）**

同一条路径在 GSC 里被拆成多行，各自积累数据，权重被稀释：

| 路径 | 变体 | 点击 / 展示 | CTR | 平均排名 |
| --- | --- | --- | --- | --- |
| 首页 | `https://www.geova.cn/` | 60 / 134 | 44.78% | 5.25 |
| 首页 | `https://geova.cn/` | 0 / 3 | 0% | — |
| 首页 | `http://www.geova.cn/` | 0 / 2 | 0% | — |
| `/about` | `/about` | 24 / 128 | 18.75% | 5.83 |
| `/about` | `/about/` | 7 / 36 | 19.44% | 5.11 |
| `/contact` | `/contact/` | 16 / 98 | 16.33% | 5.05 |
| `/contact` | `/contact` | 3 / 66 | **4.55%** | 5.03 |
| `/services` | 3 个变体 | 5/64、3/42、0/2 | — | — |
| `/services/seo-audit` | 2 个变体 | 4/16、1/7 | — | — |

**共 22 组重复路径。** `/contact` 两个变体同页，CTR 差 3.6 倍（16.33% vs 4.55%）——同内容不同 URL 的典型表现。

**实测根因（已定位，非推测）**
- `astro.config.mjs` 未设置 `trailingSlash`，Astro 默认 `"ignore"` → `/about` 与 `/about/` **都返回 200**
- `SEO.astro` 的 canonical 由 `Astro.url.pathname` 生成 → `/about` 输出 `canonical=/about`，`/about/` 输出 `canonical=/about/`，**各自指向自己，等于没有规范化**
- 站内链接写法不统一，同时存在 `/about` 与 `/about/` 两种 href
- 补充 `http://` 与无 `www` 变体分别靠 Cloudflare 301 兜底，但 301 之前已被 GSC 记过账

**已修复（本次改动，待部署验证）**
1. `astro.config.mjs` 增加 `trailingSlash: "always"` → 无尾斜杠版本统一 301 到带斜杠
2. `src/components/SEO.astro` 的 canonical 生成加 `withTrailingSlash()` 归一化 → 无论访问哪个变体，canonical 恒为同一地址（静态资源扩展名不加斜杠）
3. 服务页 title 重写（见 P0-2）

**验证方式**：部署后访问 `/about` 应返回 301 到 `/about/`；两个地址的 `canonical` 必须完全相同。

**规模核对（顺带澄清，无异常）**

| 项 | 数值 | 结论 |
| --- | --- | --- |
| GSC 已编入索引 | 59 | 正常 |
| GSC 未编入索引 | 59（45 重定向 + 7 重复 + 3 已抓取未收录 + 3 404 + 1 已发现未收录） | 45 与 7 正是 URL 变体造成的 |
| sitemap URL | 62 | — |
| 博客源文件 / dist 目录 | 52 / 52 | 一致，无多余输出 |
| 62 的构成 | 52 博客 + 5 服务页 + 工具/联系/关于 + 首页 + 博客索引 | 完全吻合 |

那 **45 条「网页会自动重定向」= URL 变体被 301/308 的记录**，**7 条「重复网页，Google 选择的规范网页与用户指定的不同」= canonical 自指冲突**。修复上面两项后，这 52 条会自然消解——**这是本次唯一一个"改一处、解一类"的技术动作**。

### 🔴 P0-2 Schema 有 8 个 error，白占位置

【规则检测】3 个 JSON-LD 块，W3C/schema.org 校验 **0 分（F）**：8 error / 4 warning / 9 info。核心问题：

- `Offer` 缺必填 `price` 与 `priceCurrency`（3 个服务项各缺一套）→ **这就是为什么你的 OfferCatalog 完全拿不到富结果**。
- `provider` 节点既无 `@type` 也无 `@value`，解析器无法识别。

**解法**：要么补真实价格（哪怕写"面议"也要用 `PriceSpecification` 的正确写法，不能留空），要么**直接删掉 Offer/OfferCatalog**——服务型业务用 `Service` + `hasOfferCatalog` 却不给价格，比不写更糟。宁可少写，不要写坏。

### 🔴 P0-3 服务页 Title 浪费了全站最值钱的位置

【规则检测】`/services/geo-optimization/` 的 title 是 `GEO 优化服务 | GEO 咨询`——**只有 2 个词，没有任何修饰、没有地域、没有信任状**。

**影响**：这是你唯一有 GSC 精确证据的词（V2.3 记录「GEO优化」排名 8），title 太弱直接压住 CTR。

**现成改法**（改 `src/pages/services/geo-optimization.astro` 的 title/description）：
```
GEO 优化服务：让品牌进入 AI 答案 | 15 分钟免费诊断 — GEOVA
```
描述里把"面向谁 + 交付什么 + 下一步"写全，别只堆平台名。

### 🟠 P1-1 全站没有价格 → 咨询前最想问的三问全缺

【规则检测】C5.1 疑问链只覆盖 3/6：缺**多少钱、有什么坑、多久见效**。
【外部核实】竞品已把报价区间公开（1 万–6 万/年），并把"首次诊断免费、3 个工作日出报告"写进页面。

**影响**：客户在你这儿得不到预期 → 不填表单，直接去报价透明的那家。这是"有流量但不询盘"的典型原因。

**解法**：服务页加一段"价格与周期"——哪怕是「诊断 XX 元 / 优化按月 / 首期建议 3 个月」，也比没有强。再补 3 条「什么情况下不建议做 GEO」，这种"劝退式内容"对 B2B 咨询的信任拉升极快，且天然是 AI 爱引用的段落形态。

### 🟠 P1-2 内容可引用性偏低（C7.1 = 31.2/100，D/F 级）

【规则检测】8 个段落块，落在 150–300 字理想区间的 **0 个**；答案块质量均值 7.5/30。
首页段落平均 48.6 字——**太碎**。碎句适合人扫读，但不利于 AI 整段摘录。你的博客长文质量不错（有独有方法论、引用 Ahrefs/SE Ranking 研究），但首页和落地页没跟上。

**解法**：每个 H2 下第一段写成「定义句 + 一个数字 + 适用边界」的 150–250 字自包含段。这是你能立刻拉开与同行差距的动作，也是最便宜的。

### 🟠 P1-3 高性能但不是内容瓶颈

【规则检测】TTFB 冷启动 5.8s，复测稳定在 **1.1–2.1s**（首次是边缘冷启动）。不算好，但**在你这阶段不是优先项**——没流量时优化 TTFB 是浪费。放 P2。

## 四、我的核心战略建议（这部分比修 bug 重要）

### 建议一：别再和榜单页抢「GEO 服务商」这个词，去抢「GEO + 你独有的证据」

现状是你和几百家付费软文在同一个池子里抢"GEO咨询"，你没有预算优势。但你有一样他们没有的东西：**一个正在公开做 GEO 实验的站点，有 41 篇原创、有 62 页可审计的内容资产**。

**把 geova.cn 本身做成案例**：单独开一个 `/case/geova-live/`（或 `/live/`），做成**持续更新的公开改造日志**——每周记录：这周改了什么、改动前后 GSC 数据、AI 平台引用变化、踩了什么坑。这个页面有三个独特价值：
1. **是销售证据**：客户要案例，你有自证的第一方数据（这恰好补了 C3.4 缺的"一手数据"）。
2. **是 AI 最爱的形态**：持续更新 + 数据 + 时间序列，天然可被引用。
3. **是差异化护城河**：服务商榜单页做不到"给自己做手术并公开"，只有你能。

### 建议二：承认「GEO」中文搜索量小，把主力往「SEO + 具体场景」迁

「GEO」是行业词，不是客户词。客户不会搜"GEO 优化"，客户搜的是：
- 「网站没询盘怎么办」「外贸独立站没流量」
- 「AI 搜索优化 怎么做」「豆包/DeepSeek 搜不到我的公司」
- 「SEO 诊断 多少钱」「网站改版后流量掉了」

**这些词有真实搜索量，且商业意图更强。** 你已有 `b2b-geo-optimization`、`geo-for-overseas-brands` 这类好文章，但标题是行业内部语言。建议做一轮**存量文章标题改造**：把"GEO 视角的 XX"改成"客户会问的原话"。这比写 30 篇新文章见效快。

### 建议三：补上「人是真的」这件事

咨询业务卖的是信任。现在站点缺三样东西：**真实姓名与照片、可核验的从业背景、哪怕一个真实项目的过程记录**。Schema 里 Organization 有主体信息，但页面上没有让"这个人是谁"落地。这是 B2B 咨询转化率最直接的杠杆，成本几乎为零。
